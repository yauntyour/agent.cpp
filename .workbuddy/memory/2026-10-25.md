# 2026-10-25

## agent.cpp：隐藏内置服务端 + 无边框 WebView2 外壳 + 频道管理重做

**目标**：桌面双击即用，服务端退到幕后；去掉日志终端；频道管理卡片化。

### 服务端（对内隐身）
- `src/main.cpp`：GUI 模式固定 `127.0.0.1`（覆盖 `server.host`），端口冲突自动回退临时端口；
  不再打印启动横幅；失败弹 `MessageBox`（`desktop::fatal_dialog`）。
- `src/desktop/webview2.cpp`：新增 `hide_console_if_standalone()`（从终端启动时保留控制台）、
  单实例互斥锁 + `activate_existing()`。
- `src/server/http_server.cpp`：`getsockname` 回读真实端口（修掉回退后端口仍显示旧值、窗口连错端口的 bug）；
  用 connect 探测端口占用（Windows 的 SO_REUSEADDR 允许抢占端口，不能靠 bind 失败判断）。
- `src/core/log.*`：新增 `set_console()`，桌面模式只落 `<root>/logs/agent.log`。
- 删除 `/api/logs` 与前端「日志」标签页、`log-box` 样式。

### WebView2 无边框窗口
- `WM_NCCALCSIZE` 返回 0 去掉系统标题栏，`WM_GETMINMAXINFO` 保证最大化贴合工作区，DWM 圆角 + 深色。
- 页面自绘标题栏（`#titlebar`）与 8 向缩放热区（`#resize-layer`），通过
  `window.chrome.webview.postMessage("win:drag|resize:*|min|max|close")` 触发
  `WM_NCLBUTTONDOWN` 进入系统拖拽/缩放循环（保留贴边分屏、双击最大化）。
- 外部链接 `NavigationStarting` 取消 + 系统浏览器打开；`NewWindowRequested` 同理；
  关掉浏览器快捷键、右键菜单、状态栏、缩放。

### 频道管理
- 后端新增 `POST /api/channels/add|update|delete`、`POST /api/channel/stop`；
  `GET /api/channels/drivers` 附带 `config` 模板与 `needs_token`。
- worker 停止机制：`bot::request_stop/stop_requested/clear_stop`，三个驱动循环改
  `while (!stop_requested(name))`；线程退出时置 `stopped` 状态。
- 前端卡片式管理：类型选择新建、状态徽标（运行中/等待扫码/正在停止/缺少 Token…）、
  启停、微信扫码、就地改 config 与 Token、删除；运行状态 3 秒轮询且不重建输入框。

### 其他
- 修掉 CSS 令牌自引用（`--ok: var(--ok)` 等），状态色在深/浅主题下都生效。
- `build.py` 编译前自动跑 `tools/embed_webui.py`，避免内嵌资源落后于 `config/webui`。
- 回归：headless 接口冒烟（频道增删改/启停、/api/logs 404）、Playwright 截图无 console error、
  GUI 实际启动 + 干净退出（rc=0）、端口冲突回退到 65258。

**遗留**：`logx::tail()` 已无调用方（保留作库接口）；前端仍依赖 CDN 的 axios/tailwind/FontAwesome/marked，
完全离线环境会白屏，需要内置才能算真正自包含。

## 第二轮：单文件产物 + 托盘 + 完全去外部依赖

**目标**：仓库根目录不留任何运行期/构建产物，发行物只有一个 exe，加系统托盘。

### 模板内嵌（删掉 config/）
- `config/webui` → `src/templates/webui`，`config/workspace` → `src/templates/workspace`；
  `tools/embed_webui.py` 换成通用的 `tools/embed_assets.py`（--src/--out/--ns/--guard/--prefix/--index）。
- 生成三份头文件：`src/server/webui_assets.hpp`（界面）、`src/core/seed_assets.hpp`
  （首次启动写盘的 workspace 模板）、`src/desktop/loader_assets.hpp`（WebView2Loader.dll）。
- `config::ensure_layout()` 改为遍历 seed 表 + base64 解码写盘（`workspace/` 前缀映射到实际工作区），
  删掉 config.cpp 里重复的 kDefault*/kFallback* 常量（约 150 行）。
- 删 `settings.example.json`（默认值本来就在 `defaults()` 里）。

### 单文件发行
- WebView2Loader.dll 内嵌 → 首次启动释放到 `<root>/runtime/`（按文件大小判断是否重写）再 LoadLibrary；
  exe 旁边不再需要 DLL。`objdump` 验证只剩系统 DLL。
- build.py 产物改为 `bin/agentcpp.exe`；新增 `--static` 走全静态链接（curl 的静态依赖链深：
  zstd/z/nghttp2/psl/idn2/ssh2/unistring/ssl/crypto/brotli/nghttp3/ngtcp2/icu）。

### 界面零外链
- 内置 `vendor/fontawesome`（core css + solid css + fa-solid-900.woff2）与 `vendor/marked.min.js`。
- axios 换成本地 20 行 fetch 封装（GET/POST + response.data + e.response.data.error）。
- 去掉 Tailwind：工具卡片改用已有的 `.tool-toggle-card*` / `.tool-toggle-switch`，toast 用 `.toast-success`；
  修 `.toggle-track` 缺 `display:block` 导致开关塌成 2px 的 bug。
- Playwright 断网路由验证：`external: []`、`errors: []`、图标走本地字体、开关 32×18。

### 托盘
- `webview2.cpp` 加 `Shell_NotifyIcon`：左键/双击显示窗口，右键菜单（显示主窗口 / 打开数据目录 / 退出）。
- `WM_CLOSE` 默认 `ShowWindow(SW_HIDE)`（首次气泡提示），托盘「退出」才 DestroyWindow；
  配置 `window.close_to_tray`、启动参数 `--no-tray`。
- `activate_existing()` 补 `!IsWindowVisible → SW_SHOW`，重复双击能从托盘拉回窗口。
- 实测：WM_CLOSE 后进程存活、第二实例 exit=0 不新起进程、日志有 `tray icon installed`。

**坑**：MSYS2 的 libcurl.a 是 unity build，`-static` 会要求全部可选依赖（含 ICU），
所以 build.py 默认仍是动态链接；零依赖发布走 `--static` 或 CMake `STATIC_BUILD=ON`。

### 静态发布（补记）
- MSYS2 的 `libcurl.a` 是 unity build，`-static` 会把 ICU/ngtcp2 全拖进来且链接失败，
  所以 `build.py --static` 这条路放弃了。
- 正解：`cmake -B build-static -DSTATIC_BUILD=ON` 用 FetchContent 编译最小 curl（schannel、HTTP only），
  产物 **5.2 MB**，`objdump` 只剩系统 DLL，`env -i` 干净 PATH 下 `--version` 正常、窗口/托盘/加载器释放全部工作。
- CMake 与 build.py 的输出目录统一到源码树 `bin/`。
